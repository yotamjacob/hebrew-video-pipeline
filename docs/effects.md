**Auto punch-in zoom (2026-08-08; smooth + face-framed 2026-08-09)** — Effects-tab toggle `#fxAutoZoom` + strength `#fxZoomStrength` (subtle 1.10 / medium 1.18 / strong 1.28). The CLIENT computes explicit windows (`_computeZoomWindows` in `app.js`: captions starting after a ≥0.35s pause, start-to-start ≥15s, the punch HOLDS for the whole caption it lands on — duration clamped 1.0-6.0s, the 6s only a long-line safety cap; since 2026-08-09 each window starts `ZOOM_LEAD` (0.5s, clamped at t=0) BEFORE its anchor caption so the camera anticipates the sentence — the zoom-list chip lookup tolerates that offset) and sends them as `caption_style.zooms` — the hook.lines contract, the server renders those exact spans and never recomputes. **The moments are user-visible**: `#zoomList` (Effects tab, `_renderZoomList`) shows each punch-in as a tappable chip (time + caption snippet); tapping toggles it into the session-scoped `_zoomOff` set, which `_zoomWindows()` filters out of BOTH the preview and the burn payload (exclusions deliberately don't persist — windows recompute deterministically, a re-edit starts clean). **Smooth camera ramp**: each window is its own `trim → zoompan → overlay(enable)` chain in `_zoom_filters` — zoompan eases the factor with a smoothstep (`_RAMP_IN=0.45s`/`_RAMP_OUT=0.35s`, clamped to half the window; mirrored by `ZOOM_RAMP_IN/OUT` in app.js) and pans so the face point stays fixed (`x='fx*(iw-iw/zoom)'`). zoompan is safe HERE (it was banned on the full track): it regenerates PTS, so each zoomed copy is trimmed to its window, re-offset with `setpts=PTS+S/TB`, and only SHOWN inside its enable window — base track + audio keep original timestamps (real-render verified: output duration byte-equal, out-of-window frames PSNR≈44dB vs source, ramp frames progress). `fps=_probe_fps(video_in)` feeds zoompan's cadence. **Face framing**: `_face_center` (pipeline_fns) extracts one frame per window (at S+0.3·D) and `_face_center_from_image` (pipeline_core) runs **YuNet** (`cv2.FaceDetectorYN` — OpenCV 5 REMOVED the legacy Haar CascadeClassifier; model ONNX baked into burn_image + light_image via `_YUNET_CMD`, path `_YUNET_MODEL_PATH`, env override `YUNET_MODEL`, fetched from media.githubusercontent because opencv_zoo is Git-LFS); largest face wins, fractions clamped 0.1-0.9/0.85, None → upper-third default (0.5, 0.30). `_zoom_spans` is the shared span validator so face indices align. `/preview_frame` detects on ITS extracted still (client sends the RAMPED numeric `zoom` at the paused t via `_zoomFactorAt`, which now eases). The instant CSS preview animates the same eased factor per frame but keeps the fixed `ZOOM_FOCUS_Y` 50%/30% origin (no detector in the browser) — the exact frame corrects the framing on settle. Zoom applies BEFORE B-roll overlays and subtitles, and forces the filter_complex path even without B-roll (`if not broll_files and not zoom_fs`). Toggle+strength persist in the `captionStyle` localStorage payload; presets omit them (`'in'` guards). Tests: `tests/backend/test_auto_zoom.py`, `tests/frontend/auto_zoom.spec.js`.
